## Implementation

- Frozen API: `Object.assign(exports,{createBroforceAudio})`, with `createBroforceAudio(getContext,getSettings)` returning `{play(name,options={}),stop()}`.
- All 19 requested effect names are distinct original combinations of oscillator sweeps, envelopes, and filtered generated noise. Rotor is a six-pulse shaped burst rather than a permanently running loop; rescue/extraction/win have harmonic rising sequences.
- No audio nodes before a valid `play()` call. The noise buffer is created lazily, reused during the session and released on stop. No samples, packages, network, DOM or existing module modifications.
- Mute/null/closed context safety; user-triggered suspended-context resume with at most one pending effect. `stop()` cancels pending replay and active/scheduled sources and disconnects their nodes; stopped instances stay stopped.
- Per-effect cooldowns, max 8 active effects / 28 simultaneous source voices, preemption for major cues, conservative master gain and quieter reduced-motion mix.
