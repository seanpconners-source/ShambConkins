## Changes and evidence

1. On portrait-sized phones, two independent player cards are stacked instead of compressed into ~158-pixel-wide cards. The cards retain portrait, player index, editable display name, status, rescue ticks/count, weapon, and ammo. Only the first player row makes room for the optional 44-pixel Canvas Pause.
2. When `showPause:false`, no Canvas Pause glyph or hit zone is emitted, and its former empty reserved width is returned to HUD cards (portrait and landscape). The real header DOM Pause/Exit/Help remains exclusively adapter-owned.
3. The mission objective uses a separately budgeted right-hand rescue badge, preventing long mission titles from hiding the rescue total. Decorative time-based glint is moved to the top rail instead of painting over the badge.
4. Public `drawBroforceHud(ctx,options)` export, deterministic paint-only behavior, empty-view handling, snapshot immutability, Canvas save/restore discipline, and player input / devil / extraction reward boundaries are unchanged.
