## API and integration contract

Exports `drawBroforceHud(ctx,{viewport,players,mission,devil,extraction,time=0,layout='auto',reducedMotion=false}={})` via `Object.assign(exports,{drawBroforceHud})`; also tolerates null options. The host passes a preconfigured device-pixel Canvas2D context, `viewport:{width,height,safeInsets:{top,right,bottom,left}}`, two player snapshot objects (name, headImage or drawHead callback, weapon/ammo/reserve, rescues, alive/down/boarded), mission objective/rescues, devil health and extraction countdown. Portrait callbacks take `(ctx,x,y,size)`. Returns `{insets,controlZones}` with a 44x44 pause target and *suggested* dual touch-island rectangles. The adapter must wire pause hit-testing and controls separately; this module does not install listeners or mutate snapshots.

Draws paired faces/initials, visible UP/DOWN/BOARD indicators, weapons/ammo, rescues, stage/objective, optional boss health, lift countdown and boarding count. Uses small opaque-edged cards with dark jungle/steel/gold palette and P1 ice-blue/P2 coral accents. When portrait columns are narrow, current ammunition is prioritized and reserve is omitted. Motion ornament is disabled for reducedMotion.
