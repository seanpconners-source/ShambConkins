## Implementation

- Frozen six-type tile enum and pure, copied row-major `Uint8Array` tiles/HP construction; defaults to 16-pixel cells. Invalid dimensions/types are rejected and original tile input is never modified.
- Solid lookup treats out-of-bounds coordinates as indestructible steel. Stone uses 3 HP, soil/wood/volatile use 1 HP, steel uses 255 HP and never takes damage.
- Pixel-space circular attacks use circle-to-tile-rectangle intersection rather than a rectangular explosion. A zero-radius attack targets only the containing cell. Off-map and invalid attacks do not change terrain; even an infinite radius is clamped to finite map bounds.
- Destroying volatile tiles queues a **40-pixel / 2-damage** secondary blast from each tile center. FIFO breadth-first events, row-major tile scanning, and a **64-event total cap including the primary blast** ensure deterministic finite chains. If the cap is reached, additional volatile tiles still break but generate no further blast events.
- `destroyed` contains each destruction once; `damaged` reports final HP for surviving tiles only; `blasts` includes the original attack plus queued secondaries in BFS order. `revision` advances once per mutating call, not once per tile or blast. No RNG, DOM, dependencies, asset or integration changes.
