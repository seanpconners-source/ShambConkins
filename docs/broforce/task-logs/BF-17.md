## Implementation

- `snapshotFighters` takes a stable, identity-deduplicated, valid-ID snapshot from `availableCharacters` for a canonical 'Sean' or 'Amber' owner key, never display names.
- `drawNextFighter` chooses from distinct identities, avoids the current identity where an alternative exists, supports injectable randomness, and handles missing/tiny pools without unwanted RNG calls.
- `devilCandidatePool` excludes already-owned identities for *both* owners, special-locked identities, Loki, duplicate aliases, and any candidate that fails real `canRecruit(..., owner, 'encounter')` checks for a participating owner.
- `chooseDevil` selects from the eligible pool or returns `null` without using randomness when empty. No grants, profile writes, selected-fighter changes, or dependencies were introduced.
