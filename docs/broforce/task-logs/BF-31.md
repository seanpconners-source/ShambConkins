## Architecture and rendering
- One shared terrain/camera with top-left BF-13 bodies converted to BF-25 feet for two owner-specific player actors; each displayed face keyed by temporary `fighterId` without altering the selected board character.
- WorldArt and optional BF-29 environment receive world-unit zoomed viewport and camera; BF-23 FX receives same local viewport; the actor/enemy/prisoner/bullet layer instead applies a world-to-screen camera transform. Shake is inside world layers only; HUD and fixed interaction annotations are screen-aligned.
- Back FX, cages, enemy types and telegraphs, projectiles, heroes, boss/extraction (BF-32 optional or procedural original fallback), front FX, screen-space locators/alerts and BF-22 HUD. Screen-filling painting, no letterboxing. Head painter counter-mirrors original portraits while allowing mirrored player bodies.
- Renderer does not register a game, mutate simulation/profile data, perform runtime network requests or introduce dependencies. Work is capped for enemies, cages and projectiles.
