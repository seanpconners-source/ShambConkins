## Implementation

- Added the frozen `Object.assign(exports,{drawBroforceWorld})` Canvas 2D API, consuming viewport, world-pixel camera, typed row-major tile map, time and quality.
- Built original layered navy/teal night jungle scenery: moon glow, gradient atmosphere, distant ridges, silhouettes, palms, suspended fog, smoke, outpost scaffolding, watchtowers, catwalks, searchlight beams, fires, and near-camera undergrowth.
- Added handcrafted 16-pixel tile variants for EMPTY/SOIL/WOOD/STONE/STEEL/VOLATILE (0–5), deterministic local wear/cracks, surface lips, chipped edges, grass, rivets and warning-orange volatile highlighting.
- Culls terrain by visible rows/columns; stable hash from tile coordinates (no `Math.random`), bounded procedural background passes, optional cached `OffscreenCanvas` tile sprites with direct Canvas fallback, and low-quality particle reduction.
- Keeps caller transform, paint settings and image smoothing state via save/restore; no assets, DOM input, network, game state, or parallel imports.
