## Implemented

- Standalone, dependency-free CommonJS-style exports `createBody` and `advanceBody`; pixel-space upper-left position, tile-index collision callback, immutable input/body handling, finite-value and timestep guards.
- Fixed 120 Hz integration with carried fractional time and spatial collision slices at or below half a tile; axis-separated wall, floor and ceiling resolution for high-speed bodies.
- Tunable touch-focused horizontal movement, gravity, terminal fall speed, coyote jumping (~0.08 s), buffered jumping (~0.10 s), hold/release jump-height control and facing direction.
- Isolated physics only: no controls, rendering, engine registry, saved game data or shared integration changes.

## Known risks / constraints

- Caller must provide correctly indexed `isSolid(col,row)` and handle out-of-level/spawn placement. There is no collision recovery for an actor initially embedded inside solid tiles.
- Internal `_stepRemainder` is intentionally carried in the returned plain-data body; the caller should preserve it between updates. `dt` is clamped to 0.10 s by default, so long pauses are not fully simulated.
- Physics feel requires actual touch-device playtesting once another worker integrates controls and level geometry.
