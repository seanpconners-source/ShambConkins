## Public API

- `createBroforceCamera({x=0,y=0,zoom=1}={})` returns a finite, independent camera value.
- `advanceBroforceCamera(camera,{players,viewport,world,dt,controlsInset=0})` returns a **new** `{x,y,zoom,tetherExceeded}` value. `x/y` are world-pixel coordinates of the canvas top-left. `world.width/height` are **world pixels**, not tile counts; `dt` is seconds; `controlsInset` is a bottom overlay clearance in CSS pixels. Input arrays, player bodies and world state are never mutated.
- `broforceWorldToScreen(camera,viewport,x,y)` and `broforceScreenToWorld(camera,viewport,x,y)` are exact inverse affine mappings for valid finite input; no CSS/DOM rotation assumptions.
- Supports two living players as one shared focus; follows surviving player if teammate is down; returns an explicit tether flag when both cannot fit above minimum legible zoom. Bound camera at world edges; center a smaller-than-screen stage.
- Motion lookahead, exponential elapsed-time smoothing, responsive minimum legible zoom and adaptive safe framing, including bottom touch controls. No imports or runtime dependencies.
