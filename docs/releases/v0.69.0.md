# v0.69.0 — Online play fixed up, tidier home screen
## 🌐 Joining a room
- **Retries by itself**, and if it still can't connect, the card says **why**: this device is offline, the site can't be reached, or the site answers but something on this device or network (an ad blocker like uBlock, an antivirus web shield, a VPN) refuses the live connection. Try again + a connection log.
- **Two tabs or windows** with the game no longer knock each other out of the same seat.
- A phone that **vanished without leaving** no longer keeps the room "full".
- **Different versions** on the two phones? The room tells you to reload the older one.
## 📶 Staying connected
- A **short drop** (phone asleep, Wi-Fi switching) gets 20 seconds to come back.
- After a reconnect only the missed messages are sent again (it used to resend the whole game).
- **Rematch** works even while the other player is still on the result card.
- **Uno** online works again.
## 🎮 Shared worlds match on both phones
- **Broforce:** enemies no longer vanish for one player while still alive and shooting on the other phone; the enemy area covers the partner's real screen (portrait or landscape).
- **Super Mario Bros., Sonic, Castlevania, Symphony of the Night, The Warriors, the zombie horde, every boss fight, Photo Hunt, Mario Kart:** one shared world, run the same on both phones.
- **Online board game:** about 7x less data, recovers by itself after lost messages, guest characters always reach the guest's phone.
## 🏠 Home screen
- One gold play button, four even tiles (Players, Online, Arcade, Collection), a small bar for About / Back up / Install / Exit.
- **Erase progress** moved to Settings.
- New **About & how to play** card with the credits.
- Taglines, Mind/Body/Spirit badges and "pass and play" removed.
## Notes
Tested headless with two simulated phones (lag, lost messages, portrait vs landscape). Not yet tried on two real phones — if a join still fails, the new error card's details tell us exactly why.
