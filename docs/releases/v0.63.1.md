# v0.63.1 — Loading Screen and Full-Screen App
## ⏳ Loading screen
No more blank logo screen while the game starts: the logo, a progress bar and what's happening (*Setting up*, *Updating to v0.63.1*, *Starting*). The bar is timed from how long the last start took on your phone.

## 📱 A real full-screen app
- The installed app opens **full screen by itself**, no tap needed (the ⤢ buttons hide inside the app).
- **shambconkins.loki-mylo.work** now serves the app's manifest, offline worker and icons, so Chrome installs a **real app**: no little Chrome badge on the icon, works **offline**, and **updates itself** with a "Downloading update · N%" bar.
- Already installed with the Chrome badge? Remove that icon and install again from Chrome's menu → *Install app*.

## Also
In a browser tab, tapping install, backup or restore first no longer uses up the automatic full screen of the first tap.
