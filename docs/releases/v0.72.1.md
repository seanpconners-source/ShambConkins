# v0.72.1 — Faster start, small updates, screen stays on
## 🚀 Opening the game
- No more long hang on the logo: the game starts in about 3 seconds instead of 9-10 (pictures and sounds now load as separate files instead of one huge page).
- When it has to download something, the loading screen shows the real progress: **Downloading v0.72.1 · 45%**, with how many MB of how many.
- No signal: the saved copy opens after 2.5 seconds.
## 📲 Updates
- The installed app downloads only what changed: a code-only release is about 8 MB instead of the whole ~200 MB game; a new portrait or song adds just that file.
- A download that stops part-way carries on where it left off.
- Pictures, songs and sounds are exactly the same quality as before.
- The first update to this version downloads everything once (Wi-Fi is best). The one-file game download is unchanged.
## 🔆 Screen stays on
- The phone no longer dims and locks itself while the game is open, also while you watch the other player. Locking it yourself still works.
## 🛹 Tony Hawk's Pro Mancala
- Trick strings, turn banners, "IS THINKING…" and popups never cover the board: they sit beside it, over the player cards and the park.
- The board lies flat whenever that makes it bigger: much larger on near-square screens like an open Fold.
- No more thin blue lines at the top and bottom of the title.
## Why there was no v0.72.0
- Its release stopped on the website host's 25 MB file limit (one picture file was too big). That file now comes in parts, and the build checks every file before a release.
