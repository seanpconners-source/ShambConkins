# v0.69.2 — Online co-op: player 1 and 2 match on both phones
## 🌐 Online co-op fix
- **Player 1 is Mario / Sonic on both phones, player 2 is Luigi / Tails on both.** When both phones picked the same name in the Online room, both played as player 1: each saw itself as Mario or Sonic, and both phones tried to run the enemies and bosses at once (enemies could jump about or go missing for one of you). Now the phone that joined the room first is player 1 and the other is player 2.
- Names, faces and characters you win still go to whoever you really are. Picking different names works as before.
## Notes
Checked with two headless browsers in one room, both set to Sean: Sonic, Super Mario Bros. World 1, Castlevania and Connect 4 each gave the phones different players and matching result cards. Full test suite run before release.
