# v0.63.0 — Install as an App
## 📲 ShambConkins on your home screen
The game can now be installed like a real app: its own SC icon, full screen with no browser bars, and the same save as the browser page it was installed from.
- Open the game from a web address (your local server or website; a file opened from Downloads can't be installed).
- Tap the new **⬇** button on the title screen, or **Settings → Play as an app → Install**, or the browser menu: Chrome *Install app*, Samsung Internet *Add page to → Home screen*, iPhone/iPad Safari *Share → Add to Home Screen*.

## 📦 New download: the app folder
`ShambConkins_v0.63.0_pwa.zip` holds the game as `index.html` plus its app manifest, icons and an offline worker. Unzip it onto your server: the installed app then **works offline** and **updates itself** when you put a newer folder there. The single HTML file still works exactly as before.

The player faces at the top left sit properly inside their round frames again.
