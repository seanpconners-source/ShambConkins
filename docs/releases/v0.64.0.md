# v0.64.0 — Online Duels
## 🌐 Play against each other on two phones
- Arcade → **🌐 Online** → type a room name. The other phone types the **same name** and joins as player 2.
- Tap **Challenge** on a game; when the other phone accepts, you both play it **at the same time from the same start**.
- Watch each other's **live score** in the corner. The result shows both scores, the winner gets the unlock roll, and **Rematch** is one tap.
- Online now: ~55 games whose 1P mode ends in a score: all three pinball tables, Broforce, Super Mario Bros., Sonic, Hole.it, Bricks Breaker Quest, DOOM, Photo Hunt, the arcade remakes and more. Games against a CPU (trivia, chess, Pong…) say *Not online yet*; those and the board game across phones come next.

Needs the internet. The rooms run on the website's Cloudflare Worker (one-time setup: `cloudflare/README.md`).
