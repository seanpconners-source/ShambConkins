# v0.66.1 — Trivia vs CPU fix
## 🤖 You can see the CPU take its trivia turns
- While it decides: "🤖 Amber (CPU) is thinking…".
- Then its answer lights up with a gold outline and a 🤖 CPU tag for about a second ("Amber (CPU) picks …"), before the result.
- The result line names who answered ("Amber (CPU): CORRECT! +3" / "BUZZ!"), and right/wrong colours are bright again.
- Wager and Survival keep answers private until both players are in, so there it only says the CPU locked in an answer.
- Works in the 1P Arcade and the 1P board game, in every trivia mode.
