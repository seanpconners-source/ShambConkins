# v0.62.2 — Save Safety
## 💾 Back up and restore from the title screen
Progress is saved inside the browser, separately for every browser and every place the game file is opened from. A different browser, a moved file or the browser clearing its data starts from nothing. Now:
- After 5 new unlocks or runs, the title screen shows **Back up progress**. One tap saves a dated backup file (`ShambConkins-save-YYYY-MM-DD.json`) to Downloads.
- An empty save shows **Restore a backup** at the bottom of the title screen: pick the file and your progress is back, in any browser.
- The game asks the browser to keep its save instead of clearing it when the phone runs low on space.
