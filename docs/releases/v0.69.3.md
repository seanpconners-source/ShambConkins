# v0.69.3 — Faster updates for the installed app
## ⬇️ Updates
- **The app checks for a new version every time you come back to it**, not only when it is opened fresh (Android often just wakes up the old one, so an update could wait days).
- **Settings → Check for updates** shows the version you're on and checks now: it says if you're up to date, or starts the download (the bar at the bottom shows progress; it's about 100 MB, so keep the app open until it finishes).
- **Restart button** when the new version is in, instead of "close and reopen the app". It waits while a minigame is running; your board game and characters are saved, so restarting loses nothing.
## Notes
This version still arrives the old way; from then on updates use the new check. Tested in a headless browser: install, a pretend next release, Check for updates, the download bar, Restart into the new version. Module check, build and core tests passed before release (the long all-games run was skipped: only the update code changed).
