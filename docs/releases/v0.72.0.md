# v0.72.0 — Faster start, small updates, a real progress bar
## 🚀 Opening the game
- No more long hang on the logo: the game starts in about 3 seconds instead of 9-10 (pictures and sounds now load as separate files instead of one huge page).
- When it has to download something, the loading screen shows the real progress: **Downloading v0.72.0 · 45%**, with how many MB of how many.
- No signal: the saved copy opens after 2.5 seconds.
## 📲 Updates
- The installed app downloads only what changed: a code-only release is about 8 MB instead of the whole ~200 MB game; a new portrait or song adds just that file.
- A download that stops part-way carries on where it left off.
- Pictures, songs and sounds are exactly the same quality as before.
- The first update to this version downloads everything once (on Wi-Fi is best). The one-file game download is unchanged.
